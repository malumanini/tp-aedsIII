# 📁 Algoritmos e Estruturas de Dados III — Trabalhos Práticos

Repositório com os Trabalhos Práticos da disciplina **Algoritmos e Estruturas de Dados III**, do curso de Ciência da Computação — **PUC Minas**.

O projeto consiste em um sistema em **Java** para gerenciamento de uma base de dados de filmes Disney, evoluindo ao longo do semestre com diferentes técnicas de manipulação, indexação, compactação e segurança de arquivos.

---

## 🗺 Etapas do trabalho

| Etapa | Tema | Status |
|-------|------|--------|
| **1** | Criação da base de dados, Manipulação de Arquivo Sequencial e Ordenação Externa | ✅ Concluída |
| **2** | Manipulação de Arquivo Indexado com Árvore B+, Hash e Lista Invertida | ⏳ Em andamento |
| **3** | Compactação com Huffman e LZW | ⏳ Pendente |
| **4** | Casamento de Padrões e Criptografia | ⏳ Pendente |

Cada etapa possui sua própria pasta/branch com o código, README específico e vídeo de demonstração.

---

## 🎬 Base de dados

**Disney Movies Dataset** (Kaggle, domínio público) — filmes do estúdio Disney, com campos de título, franquia, data de lançamento, gênero, duração, classificação indicativa e país.

---

## 🛠 Tecnologias

- **Java** puro (sem frameworks externos)
- Manipulação de arquivos via `RandomAccessFile` / `DataInputStream` / `DataOutputStream`
